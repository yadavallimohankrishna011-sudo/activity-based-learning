🐍 Python Programming – Activity-Based Learning

📌 Project Overview

This project focuses on learning Python programming through practical, activity-based exercises. It helps students understand programming concepts by solving real-world problems using simple Python programs.

🎯 Objectives

- Understand the fundamentals of Python programming.
- Develop logical thinking and problem-solving skills.
- Learn variables, data types, operators, and control statements.
- Practice loops, functions, lists, tuples, and dictionaries.
- Perform mathematical and string operations.
- Develop simple programs based on real-world applications.

🛠️ Technologies Used

- Python 3 – Programming language.
- Visual Studio Code – Code editor.
- IDLE / Jupyter Notebook – Python programming environments.

📚 Learning Activities

Activity 1: Matrix Addition and Subtraction

Perform matrix addition and subtraction using nested lists.

Activity 2: Repeated Transaction Detection

Identify duplicate transactions and detect suspicious transaction amounts.

Activity 3: Progressive Water Tariff Analysis

Calculate water bills based on household water consumption, usage slabs, fixed fees, and penalties.

Activity 4: String-Based Examination Evaluation

Evaluate student answers by comparing them with an answer key and calculate marks using negative marking.

Activity 5: Text Compression Using Character Runs

Compress a string by grouping consecutive repeated characters and compare the original and compressed lengths.

Activity 6: Campus Festival Registration and Financial Audit

Manage participant registrations, registration fees, sponsorships, and expenses to calculate the final financial balance.

⚙️ How to Run the Programs

1. Install Python 3 on your computer.
2. Install Visual Studio Code or use Python IDLE.
3. Create a Python file with the ".py" extension.
4. Write the required Python program.
5. Save the file.
6. Open the terminal.
7. Run the program using:

python filename.py
